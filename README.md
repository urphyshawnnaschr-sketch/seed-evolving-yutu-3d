# 不会建模的人，拿 AI 跑出了一个中秋玉兔摆件 🐇🥮

> 基于 **Doubao-Seed-Evolving（Seed-2.1-Pro-0915）** 的 3D Blender 自动化建模、工程源码、小红书图文与评测物料全量归档。

---

## 📖 背景故事

中秋快到了，我女儿又特别喜欢兔子。

这半年多以来，被 AI 搞得蜜汁自信的我突然想试一件以前完全不会做的事：给她做一个自己的中秋玉兔 3D 小摆件。

问题是，我不会 Blender。建模也不是一蹴而就，真正做起来肯定要一轮轮看、一轮轮改。但是 AI 会呀。

这次我用的是 **Doubao-Seed-Evolving**，目前已经同步到 **Seed-2.1-Pro-0915** 的能力版本。它强化的 Agent、Coding、看图理解和 3D 物体理解，刚好很适合这个场景：先看懂参考图，再拆结构、写脚本、跑 Blender，最后根据返图继续改。

我把它接进本地 Agent，只给了一张参考图。第一步没让它急着写代码，而是先看图：兔子、月饼、月环、底座怎么摆，哪些结构能直接用 Blender 基础几何体实现，哪些地方以后真打印还要再处理。

分析完，它才开始写 Blender Python，再调用 Blender CLI 建模。

- **V1** 很粗糙：手像在夹月饼，身体体积弱，月环和底座也有点违和。但我让它重新看自己刚出的正面和 3/4 返图，它真的开始给自己挑问题。
- **V2** 先调顺抱月饼动作、耳朵和头身比例；
- **V3** 补月饼花纹、祥云、灯笼这些中秋元素；
- **V4** 继续修脸、月环和底座；
- **V5** 不再加东西，只收动作、细节、材质和灯光。

前后一共改了 5 版。最后当然还谈不上专业精模，但从一张参考图，到能继续编辑的 `.blend`、能查看的 `.glb`，再到准备往打印走的 `.stl`，这条链真的一点点跑通了。

## 🛠️ 技术链条

1. **大模型核心**：火山引擎 Doubao-Seed-Evolving (Seed-2.1-Pro-0915)
2. **多模态视觉反馈环**：参考图结构解构 ➔ Python 脚本生成 ➔ Blender 无界面/CLI 渲染 ➔ 渲染图多模态回读自我挑刺 ➔ 增量重构调优
3. **输出物**：
   - 可编辑格式：`.blend`
   - 可视化资产：`.glb`
   - 3D 打印切片资产：`.stl`
